# AI Study Assistant

## Project Overview

The AI Study Assistant is a web application that helps students organize their school work in one place. Most students use different tools for assignment due dates, study plans, and class notes, so it is hard to see what is due and how much they have studied for each class. This project puts all of that in one website.

Students can add their courses, assignments, and exams, set deadlines and priorities, make a study schedule, upload course materials, and track how many hours they study. The AI part looks at the student's deadlines and study progress and recommends what to study next. For example, if a student has an exam in three days and has not studied much for that course, the system recommends spending more time on it. The student can accept the recommendation, which adds study sessions to the schedule, or dismiss it.

### Main Features

- Manage courses
- Add and manage assignments, exams, and other tasks
- Set deadlines and priorities
- View upcoming assignments and deadlines
- Create and manage study schedules
- Upload and organize course materials
- Track study progress
- Receive reminders about upcoming deadlines
- Get AI-based study recommendations
- Update or delete tasks and study plans

### Technology

MongoDB, Express, React, and Node.js (MERN), Docker, and a pretrained large language model for the recommendation text.
